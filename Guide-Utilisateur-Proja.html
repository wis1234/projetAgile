1. Découvrir ProJA

ProJA est une application qui permet à une équipe de travailler ensemble sur des projets : organiser des tâches, discuter, partager des fichiers, se réunir en visioconférence, et suivre l'avancement du travail en temps réel.

Concrètement, ProJA vous permet de :

  • Créer et suivre des projets avec votre équipe
  • Organiser le travail en tâches avec des échéances et des priorités
  • Discuter directement sur chaque tâche, comme dans une messagerie
  • Faire des appels vidéo ou des réunions Zoom sans quitter l'application
  • Partager des fichiers et en garder l'historique des versions
  • Recevoir des notifications en temps réel sur ce qui se passe
  • Gérer du recrutement, des abonnements, et des rémunérations si votre organisation l'utilise

Tout se passe dans votre navigateur — aucune installation n'est nécessaire.

2. Se connecter et créer son compte

Créer un compte

  1. Rendez-vous sur la page d'accueil de ProJA.
  2. Cliquez sur "S'inscrire".
  3. Renseignez votre nom, votre adresse e-mail et un mot de passe.
  4. Validez le formulaire.
  5. Un e-mail de vérification vous est envoyé : ouvrez-le et cliquez sur le lien pour confirmer votre adresse.

Se connecter

  1. Cliquez sur "Se connecter".
  2. Entrez votre e-mail et votre mot de passe.
  3. Vous accédez directement à votre tableau de bord.

Mot de passe oublié

  1. Sur la page de connexion, cliquez sur "Mot de passe oublié ?".
  2. Indiquez votre e-mail.
  3. Vous recevrez un lien pour définir un nouveau mot de passe.

💡 Astuce : si vous restez inactif sur l'application pendant longtemps (environ 30 minutes), ProJA recharge automatiquement la page pour éviter les problèmes de session expirée. C'est normal, il suffit de vous reconnecter si demandé.

3. Le tableau de bord

Le tableau de bord est la page d'accueil une fois connecté. Il vous donne une vue d'ensemble de :

  • Vos projets en cours
  • Vos tâches à faire, en cours et terminées
  • Les activités récentes de votre équipe
  • Vos notifications

C'est le point de départ pour naviguer vers le reste de l'application, via le menu principal.

4. Gérer un projet

Un projet est le conteneur principal de votre travail d'équipe : il regroupe des tâches, des membres, des sprints, des fichiers et des réunions.

Créer un projet

  1. Allez dans "Projets" depuis le menu.
  2. Cliquez sur "Nouveau projet".
  3. Renseignez :
    • Le nom du projet
    • Une description (optionnelle)
    • Un lien de réunion externe si vous en avez un (optionnel)
    • Le statut initial (par défaut : "Nouveau")
  4. Validez. Vous devenez automatiquement manager de ce projet.

Les statuts d'un projet

Un projet évolue à travers plusieurs statuts :

  • Nouveau : le projet vient d'être créé
  • Démarrage : le projet commence tout juste
  • En cours : le travail est actif
  • Avancé : le projet est bien avancé
  • Terminé : le projet est achevé
  • Suspendu : le projet est mis en pause temporairement

Seul un manager ou un administrateur peut changer le statut, et uniquement vers certains statuts autorisés (par exemple, on ne peut pas passer directement de "Nouveau" à "Terminé").

Ajouter des membres à un projet

  1. Ouvrez le projet concerné.
  2. Dans la section "Actions rapides", cliquez sur "Ajouter un membre".
  3. Recherchez la personne par son nom ou son e-mail.
  4. Choisissez son rôle dans le projet (membre, manager, observateur).
  5. Validez.

Consulter un projet

La page d'un projet vous montre :

  • Les informations générales (nom, date de création, description)
  • Un accès rapide aux appels (Zoom et ProJA Meet)
  • Des statistiques : tâches terminées, en cours, fichiers, commentaires
  • La liste des sprints
  • La liste des tâches avec un aperçu rapide
  • Les membres du projet et leur rôle
  • La progression de chaque membre (nombre de tâches terminées)
  • Un graphique d'évolution des tâches sur les 30 derniers jours

Voir qui contribue le plus aux discussions

Sur la page du projet, dans la carte des statistiques, cliquez sur "Voir détail" sous le compteur de commentaires. Une fenêtre s'ouvre avec :

  • Le classement des membres les plus actifs dans les discussions (🥇🥈🥉)
  • Un graphique comparant le nombre de commentaires par personne

C'est un excellent moyen de repérer les collaborateurs les plus engagés dans les échanges d'équipe.

Modifier un projet

  1. Ouvrez le projet.
  2. Cliquez sur "Modifier le projet" (visible pour les managers et administrateurs).
  3. Changez les informations souhaitées.
  4. Enregistrez.

Supprimer un projet

La suppression d'un projet est volontairement stricte, car elle efface aussi tout ce qu'il contient (tâches, fichiers, discussions, etc.) :

  • Si vous êtes administrateur système : vous pouvez supprimer directement, après une simple confirmation.
  • Si vous êtes manager (non administrateur) : la suppression nécessite le consentement de tous les membres du projet. Chaque membre doit saisir son propre mot de passe de compte dans la fenêtre de confirmation. Le projet n'est supprimé que lorsque tous les membres ont donné leur accord.

Cette double sécurité évite qu'un projet soit supprimé par erreur ou sans l'accord de l'équipe.

Exporter les informations d'un projet

Depuis les "Actions rapides" de la page projet, vous pouvez exporter :

  • Un journal complet du projet (format texte)
  • Un planning au format PDF, avec les sprints et les tâches organisées

5. Gérer les tâches

Les tâches sont les unités de travail concrètes assignées aux membres d'un projet.

Créer une tâche

  1. Allez dans "Tâches" ou depuis un projet, cliquez sur "Nouvelle tâche".
  2. Renseignez :
    • Le titre
    • Une description
    • Le projet associé
    • La priorité : Faible, Moyenne ou Haute
    • Le statut initial : À faire, En cours ou Terminé
    • La personne assignée
    • La date d'échéance
    • Si la tâche est rémunérée (le cas échéant)
  3. Validez.

Vue Tableau et vue Cartes

La liste des tâches peut s'afficher de deux façons, au choix :

  • Vue Tableau : idéale pour parcourir rapidement beaucoup de tâches et trier par colonne.
  • Vue Cartes : plus visuelle, avec les informations principales sur chaque carte.

Basculez entre les deux via les boutons en haut de la liste des tâches.

Filtrer et rechercher des tâches

Cliquez sur "Filtres & Recherche" pour affiner la liste selon :

  • Un mot dans le titre
  • Le statut (à faire, en cours, terminé, en retard)
  • La priorité
  • Le projet
  • La personne assignée
  • Une plage de dates d'échéance

Un badge affiche le nombre de filtres actifs, et un bouton permet de tout réinitialiser en un clic.

Suivre la progression de l'équipe

Cliquez sur "Voir les progrès" pour afficher, pour chaque membre :

  • Le pourcentage de tâches complétées
  • Le détail : à faire / en cours / terminé
  • Le taux de tâches rendues à temps vs en retard

Les trois membres les plus performants sont mis en avant avec des médailles 🥇🥈🥉.

Modifier ou supprimer une tâche

Ouvrez la tâche concernée, puis utilisez les boutons "Modifier" ou "Supprimer" (visibles selon vos droits).

Tâches verrouillées

Si une tâche appartient à un sprint dont le délai est dépassé, elle est automatiquement verrouillée (un cadenas 🔒 s'affiche) tant qu'un chef de projet ne prolonge pas le sprint. Une bannière d'alerte apparaît en haut de la liste des tâches pour vous prévenir.

6. Le tableau Kanban

Le Kanban offre une vue en colonnes (À faire / En cours / Terminé) pour visualiser et déplacer les tâches par glisser-déposer.

  1. Allez dans "Kanban" depuis le menu ou le bouton dédié sur la page des tâches.
  2. Faites glisser une tâche d'une colonne à une autre pour changer son statut instantanément.
  3. Le changement est enregistré automatiquement, aucune validation supplémentaire n'est nécessaire.

7. Discuter et commenter

Chaque tâche dispose de son propre espace de discussion, semblable à une messagerie instantanée.

Écrire un commentaire

  1. Ouvrez une tâche.
  2. Allez dans l'onglet "Discussions".
  3. Tapez votre message dans la zone de texte en bas.
  4. Appuyez sur Entrée (ou cliquez sur le bouton d'envoi) pour publier.

Répondre à un commentaire précis

Survolez un message et cliquez sur l'icône de réponse 💬 pour répondre directement à ce message.

Réagir avec un émoji

Survolez un message et cliquez sur l'icône sourire 😊 pour ajouter une réaction rapide (👍 ❤️ 😂 etc.). Vous ne pouvez avoir qu'une seule réaction active par message — en choisir une nouvelle remplace la précédente.

Envoyer un message vocal

Cliquez sur l'icône micro 🎙️ pour enregistrer un message vocal, puis envoyez-le comme un message classique.

Emoji et autocollants

Le bouton sourire à côté de la zone de texte ouvre un sélecteur d'émojis et d'autocollants pour enrichir vos messages.

Modifier ou supprimer votre message

Survolez votre propre message pour faire apparaître les boutons "Modifier" ✏️ et "Supprimer" 🗑️.

Voir qui est en ligne

Dans l'en-tête de la discussion, les avatars des membres actuellement connectés à cette tâche s'affichent avec un point vert. Vous voyez aussi en temps réel qui est "en train d'écrire...".

Accusés de lecture

Une double coche ✓✓ apparaît sous vos messages ; elle devient bleue lorsque le destinataire a lu votre message.

Recevoir les discussions par e-mail

Dans l'en-tête de la discussion, une icône enveloppe ✉️ permet d'activer ou de désactiver l'envoi d'une copie des commentaires par e-mail.

8. Les sprints

Un sprint est une période de travail définie (par exemple deux semaines) durant laquelle une équipe se concentre sur un ensemble précis de tâches.

Créer un sprint

  1. Depuis un projet, allez dans "Actions rapides" puis "Ajouter un sprint".
  2. Renseignez :
    • Le nom du sprint
    • Un objectif (optionnel)
    • Les dates de début et de fin
  3. Validez.

Sprint terminé et tâches verrouillées

Lorsqu'un sprint dépasse sa date de fin, toutes les tâches inachevées qui lui sont rattachées sont automatiquement verrouillées. Une bannière d'avertissement s'affiche pour prévenir l'équipe. Seul un chef de projet peut débloquer la situation en prolongeant le sprint.

9. Réunions Zoom

ProJA permet de planifier et suivre des réunions Zoom directement depuis un projet, sans changer d'application.

Planifier une réunion

  1. Ouvrez un projet.
  2. Cliquez sur le bandeau "Réunions Zoom".
  3. Cliquez sur "Planifier / voir".
  4. Renseignez le sujet, la date et la durée de la réunion.
  5. Validez : la réunion est créée et visible par les membres du projet.

Rejoindre une réunion en cours

Si une réunion Zoom est active, un badge "En cours" apparaît sur le bandeau Zoom de la page projet, avec un bouton "Rejoindre" pour y accéder directement.

10. ProJA Meet — appels audio et vidéo

ProJA Meet est le système d'appel vidéo natif de l'application (jusqu'à 100 participants simultanés), sans dépendre de Zoom.

Démarrer ou rejoindre un appel

  1. Ouvrez un projet.
  2. Repérez la carte "Appels & réunions", section ProJA Meet.
  3. Cliquez sur "Démarrer / Rejoindre".
    • Si aucun appel n'est en cours, un nouvel appel démarre et les autres membres du projet reçoivent une notification.
    • Si un appel est déjà en cours (le nom de la personne qui l'a démarré s'affiche), vous rejoignez directement cet appel existant.

Pendant l'appel

  • Micro / Caméra : icônes en bas de l'écran pour activer/couper votre son et votre image.
  • Partage d'écran 🖥️ : partagez votre écran avec les autres participants.
  • Lever la main ✋ : signalez que vous souhaitez intervenir.
  • Réactions 😊 : envoyez des émojis flottants visibles par tous, sans interrompre la conversation.
  • Liste des participants 👥 : consultez qui est présent dans l'appel.
  • Plein écran : agrandissez la fenêtre d'appel.

En tant qu'hôte

Si vous avez démarré l'appel (ou si vous êtes manager/administrateur du projet), vous pouvez couper le micro ou la caméra d'un autre participant en survolant sa vignette vidéo.

Quitter l'appel

Cliquez sur le bouton rouge "Quitter" en bas de l'écran d'appel.

11. Fichiers et documents

Ajouter un fichier à une tâche

  1. Ouvrez une tâche.
  2. Allez dans l'onglet "Ressources".
  3. Cliquez sur "Ajouter un fichier".
  4. Sélectionnez le fichier depuis votre ordinateur (ou depuis Dropbox si cette option est configurée).
  5. Ajoutez une description si besoin, puis validez.

Consulter et télécharger un fichier

Cliquez simplement sur la vignette du fichier pour l'ouvrir, ou utilisez le bouton de téléchargement.

Historique des versions

Chaque fichier conserve un historique de ses versions précédentes. Vous pouvez consulter une ancienne version ou la restaurer si nécessaire.

Protéger un fichier par mot de passe

Certains fichiers peuvent être protégés par un mot de passe pour en restreindre l'accès, même au sein du projet.

Gérer les accès à un fichier

Vous pouvez définir précisément quels membres ont accès à un fichier particulier, au-delà de leur simple appartenance au projet.

12. Notifications

ProJA vous informe de ce qui se passe via plusieurs canaux, que vous pouvez configurer selon vos préférences.

Notifications dans l'application

Une cloche 🔔 dans le menu principal affiche vos notifications récentes : nouveaux commentaires, changements de statut, appels démarrés, etc.

Notifications push (navigateur)

Vous pouvez activer les notifications push pour recevoir des alertes même lorsque ProJA n'est pas ouvert dans votre navigateur :

  1. Allez dans votre profil > Préférences de notification.
  2. Autorisez les notifications lorsque votre navigateur vous le demande.

Notifications par e-mail

Certaines actions (nouveaux commentaires, échéances de tâches) peuvent aussi vous être envoyées par e-mail, selon vos préférences définies dans votre profil.

13. Recrutement

Si votre organisation utilise le module de recrutement de ProJA :

Publier une offre

  1. Allez dans "Recrutement".
  2. Cliquez sur "Nouvelle offre".
  3. Renseignez le poste, la description, le type de contrat, le niveau d'expérience requis, etc.
  4. Choisissez de publier immédiatement ou d'enregistrer en brouillon.

Statuts d'une offre

  • Brouillon : non visible publiquement, encore en préparation
  • Publiée : visible et ouverte aux candidatures
  • Clôturée : n'accepte plus de nouvelles candidatures (automatique après la date limite)

Gérer les candidatures

  1. Ouvrez l'offre concernée.
  2. Consultez la liste des candidatures reçues.
  3. Ouvrez une candidature pour voir le CV et les documents joints.
  4. Changez le statut de la candidature (en cours d'examen, acceptée, refusée, etc.).
  5. Exportez la liste des candidatures au format Excel si besoin.

14. Abonnements et paiements

Consulter les plans disponibles

Allez dans "Abonnements" pour voir les différentes formules proposées.

Souscrire à un abonnement

  1. Choisissez le plan qui vous convient.
  2. Cliquez sur "Souscrire".
  3. Vous êtes redirigé vers le tunnel de paiement sécurisé FedaPay.
  4. Complétez le paiement selon le moyen proposé (mobile money, carte, etc.).
  5. Une fois le paiement confirmé, votre abonnement passe au statut actif.

Gérer votre abonnement

Depuis "Paramètres" > "Facturation", vous pouvez consulter l'état de votre abonnement en cours et son historique.

15. Rémunérations

Pour les tâches marquées comme rémunérées :

Renseigner ses informations de paiement

  1. Ouvrez la tâche rémunérée concernée.
  2. Allez dans l'onglet "Rémunération".
  3. Choisissez votre opérateur de paiement mobile (MTN, Moov, Celtis) et indiquez votre numéro de téléphone.
  4. Enregistrez.

Suivre le statut de paiement

Le statut affiché évolue de "En attente" à "Payé" une fois que le paiement a été validé par un manager ou un administrateur.

Pour les managers : valider un paiement

Sur la page de la tâche, dans la liste des paiements de tous les membres, cliquez sur "Valider le paiement" en face de la personne concernée.

Télécharger un reçu

Une fois un paiement validé, un bouton "Télécharger le reçu" apparaît, permettant d'obtenir un justificatif PDF.

16. Mon profil et mes paramètres

Modifier ses informations personnelles

  1. Cliquez sur votre avatar en haut à droite, puis "Profil".
  2. Modifiez votre nom, votre photo, votre e-mail.
  3. Enregistrez.

Changer son mot de passe

Dans la même page de profil, une section dédiée permet de définir un nouveau mot de passe.

Informations bancaires

Une section spécifique permet d'enregistrer vos coordonnées bancaires si votre organisation en a besoin pour les rémunérations.

Supprimer son compte

Une option de suppression de compte est disponible en bas de la page de profil. Cette action est définitive.

Thème sombre / clair

ProJA s'adapte automatiquement à la préférence de votre système (thème sombre ou clair). Vous n'avez rien à configurer, cela se fait tout seul.

17. Rôles et permissions

Chaque membre d'un projet possède un rôle qui détermine ce qu'il peut faire :

Rôle Icône Peut faire
Membre 👤 Consulter le projet, gérer ses propres tâches, discuter, participer aux appels
Manager 👑 Tout ce qu'un membre peut faire, + modifier le projet, gérer les membres, valider les paiements, changer le statut du projet
Administrateur système 🛡️ Accès complet à toute l'application, y compris la suppression directe de projets

Un manager peut ajouter ou retirer des membres, et modifier leur rôle, depuis la page "Membres du projet".

18. Messagerie

En dehors des discussions liées aux tâches, ProJA propose aussi un espace de messagerie générale pour échanger avec d'autres utilisateurs de l'application, accessible depuis le menu "Messages".

19. Astuces et bonnes pratiques

  • Utilisez les filtres sur la page des tâches pour ne pas vous sentir submergé par le volume total de tâches de l'organisation.
  • Activez les notifications push pour ne rien manquer, surtout si vous n'avez pas ProJA ouvert en permanence.
  • Consultez régulièrement la vue "Progrès" sur la page des tâches ou du projet pour repérer les points de blocage de l'équipe.
  • Réagissez avec des émojis plutôt que d'écrire un commentaire complet pour de simples accusés de réception ("vu", "ok") — cela allège les discussions.
  • Prolongez vos sprints à temps : un sprint qui expire verrouille automatiquement les tâches inachevées, ce qui peut bloquer une partie de l'équipe si personne n'y prête attention.
  • Utilisez ProJA Meet pour les échanges rapides internes, et réservez Zoom pour les réunions plus formelles nécessitant l'enregistrement ou des intégrations externes.

20. Questions fréquentes et dépannage

Je ne reçois pas de notifications, que faire ? Vérifiez que vous avez bien autorisé les notifications dans votre navigateur, et consultez vos préférences dans votre profil.

Ma session a expiré, pourquoi ? Après une longue période d'inactivité (environ 30 minutes), ProJA vous déconnecte par sécurité. Reconnectez-vous simplement avec votre e-mail et mot de passe.

Je ne peux pas supprimer un projet seul en tant que manager, pourquoi ? C'est volontaire : seul un administrateur système peut supprimer un projet directement. Un manager doit obtenir le consentement (mot de passe) de tous les membres du projet.

Une tâche est verrouillée avec un cadenas, que faire ? Cela signifie que le sprint auquel elle appartient est arrivé à échéance. Un manager doit prolonger le sprint pour débloquer la tâche.

Je ne peux pas rejoindre un appel ProJA Meet, l'image reste bloquée sur "Connexion..." Cela peut arriver sur certains réseaux très restrictifs (Wi-Fi d'entreprise strict, certains réseaux mobiles). Essayez de changer de réseau, ou contactez votre administrateur technique.

J'ai plusieurs réactions actives sur un même message, est-ce normal ? Non, une seule réaction par personne et par message est permise. Si vous en sélectionnez une nouvelle, l'ancienne est automatiquement retirée.

Comment savoir qui a le plus contribué aux discussions d'un projet ? Sur la page du projet, cliquez sur "Voir détail" sous la carte des commentaires pour afficher le classement complet.

Ce guide couvre les fonctionnalités principales de ProJA. Pour toute question non couverte ici, contactez votre administrateur ou l'équipe support de votre organisation.
